# @amlplugins/amazon-sns

Native `@aws-sdk/client-sns` SDK re-exported under the `@amlplugins` namespace.

> Amazon SNS — pub/sub topics, SMS, email, mobile push, fan-out to SQS/Lambda/HTTP.

## Install

```bash
npm install @amlplugins/amazon-sns
```

## Use

```ts
import { /* named exports from @aws-sdk/client-sns */ } from "@amlplugins/amazon-sns";
// or
import sdk from "@amlplugins/amazon-sns";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
